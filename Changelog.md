# Release v1.0

Major release iteration where the entire application went through significant upgrades from the previous versions. 

**Frontend**
* UI and UX thoroughly renovated
* Using RWR algorithm for frontend <> backend communication
* Expanded Menu bar - ( Home, Test View, Collections, Repo View, Web View, Import / Export )

**Backend**
* Folder organization is completely modified
* Advanced algorithms for bulk operations like merging, tagops, etc
* Storage model is streamlined with flattened EQP data in History and globalEQPData folders.
* Organized data from flattened EQP Data are put into SQLite files as referred to by the applications
* Two levels of Tagging. ListViews:Tags(EQP:Tags)
